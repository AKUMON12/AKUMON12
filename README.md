# 📁 Project Philosophy

For my portfolio, I want to communicate projects through **context rather than walls of text**.

Each project should answer four questions quickly:

### 01 — What is it?

A concise explanation of the project.

### 02 — Why did I build it?

The problem, requirement, or motivation behind it.

### 03 — What did I do?

My role, technical approach, and responsibilities.

### 04 — What did I learn?
